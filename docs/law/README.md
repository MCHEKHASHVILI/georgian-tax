# The law this package encodes

`tax-code-consolidated.txt` is the text of the Tax Code of Georgia (№3591-IIს, 17 September 2010) as consolidated on matsne.gov.ge, extracted from the official PDF. Article citations in `src/` (`#[Article('166')]`, `new Citation('206.1.ა')`) refer to it.

Official legal texts of Georgia are not protected by copyright (Law on Copyright and Neighbouring Rights, Art. 8). Check matsne.gov.ge for amendments after this consolidation.
